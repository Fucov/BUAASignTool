# BUAA Sign Tool (北航课程打卡系统)

一款专为北航学子打造的极简主义桌面端课程辅助工具。支持查看每周课表、课程状态追踪，以及校内/校外环境下的**一键自动打卡**功能。

---

## 核心特性

- **极简主义 UI**：拒绝视觉噪音，专注核心信息，提供如同高端画廊般的清爽体验。
- **双模网络穿透**：
  - **校园直连**：仅需学号即可登录。
  - **校外穿透**：使用统一身份认证账号密码，无需复制 cURL。
- **双端口兜底机制**：优先使用新 API 端口（8347），失败时自动回退到旧端口（8346）。
- **单体桌面应用**：基于 `pywebview` 架构，轻量、跨平台。

---

## 使用教程

### 环境准备

```bash
pip install -r requirements.txt
```

启动程序：
```bash
python app.py
```

### 校园直连

处于校园网环境时：
1. 选择"校园直连"
2. 输入学号
3. 点击登录

### 校外网络（WebVPN）

处于校外网络时：
1. 选择"校外网络"
2. 输入**账号**（统一身份认证账号，通常与学号相同）
3. 输入**密码**（统一身份认证密码）
4. 点击"VPN 登录"

> [!NOTE]
> 若需切换账号，请先点击"退出登录"按钮退出当前会话，再重新登录。
